# 03_review — Review

## Purpose

Verify work against success criteria.

## Inputs

- Work product from 02_execute
- `TASK.md` success criteria and deliverables
- Any review-specific references named in `pipeline.md`

## Process

1. Check each success criterion; record pass/fail with evidence.
2. Verify material claims/calculations/citations.
3. Identify needed revisions or user decisions.
4. Record final decision.

## Outputs / exit criteria

- Findings with evidence recorded.
- Revisions done or accepted as unresolved.
- Deliverables identified for delivery.
