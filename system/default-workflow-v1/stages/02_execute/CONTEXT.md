# 02_execute — Execute

## Purpose

Produce the work product.

## Inputs

- `TASK.md` success criteria and deliverables
- Task-specific source files named in `TASK.md` or prior stage handoff
- `work/` directory or explicit output path

## Process

1. Read only the inputs listed above.
2. Work in `work/` or named output location.
3. Record material decisions in `LOG.md`.
4. Confirm planned outputs exist.

## Outputs / exit criteria

- Planned work product exists.
- Decisions visible in `LOG.md`.
- Review stage inputs are clear.

## Handoff

Next stage: 03_review or 04_deliver_archive.
Pass output path and verification target to next stage contract.
