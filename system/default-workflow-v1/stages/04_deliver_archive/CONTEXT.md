# 04_deliver_archive — Deliver and Archive

## Purpose

Finalize, hand off, archive.

## Inputs

- Reviewed work product
- `TASK.md` required deliverables
- `STATUS.md` and `pipeline.md`

## Process

1. Hand off only if needed.
2. Verify every required deliverable exists.
3. Add archive note: status, workflow version, limitations.
4. Move entire task directory to `archive/completed-tasks/`.
5. Add entry to root `INDEX.md`.
6. Clear root `STATUS.md` active-task pointer; append closeout to root `ROOT_LOG.md`.

## Outputs / exit criteria

- Deliverables verified.
- Complete task archived.
- `INDEX.md` and root `STATUS.md` current.

## Handoff

None. Workspace ready for next task.
